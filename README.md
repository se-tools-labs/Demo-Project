# Student Management System

## Project Description
The Student Management System is a simple software project designed to manage student information.

## Features
- Add student information.
- View student records.
- Update student details.
- Delete student records.

## Technologies Used
- Python
- Git
- GitHub

## Installation
1. Clone or download the repository.
2. Open the project folder.
3. Run the application using Python.

This project was developed for learning purposes as part of Software Engineering Tools.
